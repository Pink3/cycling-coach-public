## 1. 每日流程（以晚间训练作息为例）

| 时间 | 发生什么（微信推送） | 你要做什么 |
|---|---|---|
| 17:00 | 收到「同步手表数据提醒」（含今日状态块） | 打开 Garmin/Wahoo 伴侣 App 等自动同步，确保睡眠/HRV 已上传 Intervals.icu |
| 18:00 | 收到「📋 每日骑行训练分析」完整报告 | 阅读：状态摘要 → 今晚计划 → 理由 → 补给 |
| 19:00-20:45 | 按计划训练 | 按报告中的开练时间、目标区间执行（见第 2 节） |
| 21:00 | 收到「该饮食打卡啦」（含今日状态块） | 按模板回复三餐/加餐/水分（见第 3 节） |
| 21:30-22:00 | 入睡 | 按 3:10 起床作息倒推，训练后 1-1.5h 内入睡 |

> 三条推送均通过 PushPlus 发到微信；未配置 PushPlus 时，提醒仍在豆包会话内进行。时间可按你的作息调整：早间/午间训练者把 18:00 分析改到训练前 1-2 小时。

## 1.1 如何读微信推送

**每条推送开头的「📊 今日状态」块（两行）**

```
睡眠 5.5h ｜ HRV 45 ｜ 静息心率 57 ｜ 压力 —
CTL 23.1 ｜ ATL 30.5 ｜ TSB -7.4（最佳训练区）｜ 体重 —
```

- **第 1 行 = 恢复信号**：睡眠不足 6h、静息心率抬升、HRV 下降 → 身体在预警，训练要降档；
- **第 2 行 = 训练负荷**：CTL 是长期适应度、ATL 是近期疲劳、TSB = CTL − ATL；
- **TSB 解读速查**：`-10 ~ +5` 最佳训练区（可上强度）；`-30 ~ -10` 过度训练区（只做计划内课）；`< -30` 高风险（强制减量）；`> +15` 比赛窗口；
- 缺失项标 `—`（如压力值未同步），不影响评估。

**18:00 完整报告三段式**

1. **一、当天状态摘要**：最近训练量（类型/时长/IF/负荷）+ 昨天状态 + 睡眠恢复 + 负荷指标 → 一眼看今天身体"能不能练"；
2. **二、今晚训练计划**：训练类型、目标区间、热身/主项/冷身、开练时间、安全阀 → 直接照做；
3. **三、决策理由**：规则命中点（TSB 区间 / 睡眠 / 前一天状态）+ 为什么这样安排 → 理解而非盲从。

## 2. 如何执行训练计划

每晚报告会给出：训练类型、目标区间、时长、热身/主项/冷身、开练时间、补水补食。

**强度锚点（二选一，优先功率）**

| 区间 | %FTP（功率 W） | 心率（bpm） | 体感 |
|---|---|---|---|
| Z1 恢复 | <55%（<110W） | <114 | 几乎不喘 |
| Z2 有氧 | 55-75%（110-150W） | 114-140 | 可交谈 |
| Z3 节奏 | 76-90%（152-180W） | 141-158 | 说话费力 |
| Z4 阈值 | 91-105%（182-210W） | 159-175 | 短句 |
| Z5 VO2max | 106-120%（212-240W） | 176-190 | 无法说话 |

（示例为 FTP 200W / LTHR 189bpm，实际以教练按你的数据计算为准）

**执行要点**
- 热身务必做满：高强度课前 15-20 分钟渐进到目标区间；
- 间歇课**严格按组数执行**，不超量（历史上超量 3 倍是过度训练的直接原因）；
- 状态不好（腿沉/心率漂移大）主动降档，训练日志会自动记录；
- 冷身 5-10 分钟轻松踩，让心率回落到 Z1 再下车。

## 3. 如何饮食打卡

21:00 收到提醒后，直接按模板回复：

```
早餐：粥+鸡蛋+包子
午餐：米饭+鸡胸+青菜
晚餐：米饭+牛肉+西兰花
加餐/补给：练前香蕉+练后牛奶
水分：约 2.5L
```

教练会：
1. 归档到 `data/diet-log.md`；
2. 对照当日训练强度评估（80kg 参考：休息日碳水 240-400g / 高强度日 480-800g，蛋白 96-160g，水分 2.4-3.2L）；
3. 给出次日调整建议（如"高强度课前碳水不足，明早加一顿高碳水早餐"）。

**晚间训练版补给口诀**
- 练前 1.5-3h：晚餐 7 分饱（17:30-18:00 吃）；
- 高强度课练前 15-30min：香蕉/能量胶 20-30g 快碳水；
- 练后 30-60min：80-96g 碳水 + 20-40g 蛋白（牛奶+香蕉/三明治）；
- 21:30 后不大吃，避免影响入睡。

## 4. 力量与核心训练（恢复达标后启动）

系统在 **TSB > -10 且连续 2-3 晚睡眠 ≥6h** 时自动提醒启动：

| 安排 | 内容 | 时间 |
|---|---|---|
| 低强度骑行日 | 力量 20min：高脚杯深蹲 3×10-12 + 罗马尼亚硬拉 3×10 + 站姿提踵 3×15 | 19:00 先力量，19:30 开骑 Z2 |
| 休息日 | 全身循环 20min 或核心 10min | 晚间 |
| 核心（每周 2-3 次） | 平板 3×40s + 侧平板 3×30s/侧 + 死虫 3×8/侧 + 鸟狗 3×8/侧 + 臀桥 3×12 | 骑行后或休息日 |

**原则**：低重量高次数、不做到力竭、不与 VO2max/阈值课同日、腰膝不适立即停。

## 5. 常用指令速查

| 场景 | 对教练说 |
|---|---|
| 每日计划已自动推送 | （无需指令） |
| 临时看状态 | 「今天状态怎么样？该练什么？」 |
| 改计划时间 | 「把每日分析改到 19:00」 |
| 复盘一周 | 「复盘本周训练数据」 |
| 查趋势 | 「近 7 天睡眠/HRV/TSB 趋势如何？」 |
| 改饮食目标 | 「我最近想增肌/减重，调整饮食目标」 |
| FTP 复测 | 「安排一次 20 分钟 FTP 测试」 |
| 力量训练 | 「现在可以开始力量训练了吗？」 |
| 打卡 | 直接按第 3 节模板回复即可 |
| 推送测试 | 「推送一条测试」 |

## 6. 常见问题

| 问题 | 说明 |
|---|---|
| 报告说"睡眠未同步" | 手表数据没同步；17:00 提醒时打开伴侣 App 等同步 |
| 微信没收到推送 | 检查 PushPlus token 是否有效（见部署指南 3.4/故障排查） |
| 推送排版乱了 | 多为用了 Markdown 换行；规范见 `docs/push-notification.md` |
| 今天特别累/生病 | 直接说"今天休息"，教练会把计划顺延 |
| 强度课频繁降档 | 通常是睡眠债累积；优先补睡 1-2 晚 6h+，比硬练有效 |
| 体重趋势 | 系统随 wellness 记录体重，减重期每周看一次趋势即可 |
| 想看历史 | 训练日志 `data/training-log/` + JSON 快照 `data/raw/` |

---

## 7. 安全红线

- 出现胸痛、晕眩、异常疲劳 → **立即停练并就医**；
- 连续高强度后睡眠不足 → 系统会强制减量，请照做；
- 极端节食不可取；热量底线男性 ≥ 1500 kcal/日；
- 力量训练腰/膝不适立即停止，重量宁轻勿重。
